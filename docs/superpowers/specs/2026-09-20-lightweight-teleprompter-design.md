# 轻量级口播提词器设计

## 目标

构建一个无需后端、无需安装、可在现代桌面浏览器直接运行的网页版口播提词器。用户录入稿件后，可实时调整字号、颜色、背景和总播放时长；开始后，稿件以恒定速度向上滚动，首行从预览区域垂直中心开始，末行到达中心时停止。

## 范围

本次实现包括：

- 多行稿件录入、编辑和清空。
- 字号、文字颜色、背景颜色实时配置。
- 针对文本选区单独设置颜色和字号，并支持恢复默认。
- 总播放时长输入。
- 开始、暂停、继续、重置和全屏控制。
- 点击提词预览区域可开始、暂停、继续或重新播放。
- 以 `requestAnimationFrame` 和 `transform` 驱动的匀速滚动。
- 稿件与配置的本地自动保存和恢复。
- 窗口尺寸变化或关键配置变化后的位置重算。
- 自动化单元测试和浏览器交互验收。

本次不实现镜像翻转、行高亮、语速微调、倒计时和稿件模板。

## 页面结构

页面采用横向双栏布局：

- 左侧控制区：稿件编辑、清空按钮、字号滑块、颜色选择器、时长输入。
- 右侧预览区：固定在可用空间中的提词舞台、状态提示、全屏及滚动控制。
- 窄屏时改为上下布局，保证输入和预览都可使用。

控制区保持工具型界面风格，信息密度适中，按钮和配置项不随内容跳动。

## 模块边界

- `index.html`：语义化页面结构和控件。
- `styles.css`：响应式布局、视觉样式、全屏模式和控件状态。
- `prompt-engine.js`：不依赖 DOM 的滚动计算与状态机。
- `style-ranges.js`：选区样式区间的新增、拆分、删除和文本编辑同步。
- `app.js`：DOM 绑定、配置持久化、动画循环和全屏控制。
- `tests/prompt-engine.test.cjs`：核心计算与状态转移的单元测试。

## 滚动模型

预览舞台高度记为 `viewportHeight`，稿件内容高度记为 `contentHeight`。

初始状态：

```text
offset = 0
首行顶部位于 viewportHeight / 2
```

内容容器使用居中对齐，并通过 `translate3d(0, offset, 0)` 向上移动。

总滚动距离直接等于稿件内容高度：

```text
distance = contentHeight
```

内容容器初始向上偏移首行行高的一半，使首行文字的视觉中心与预览区中心重合。该距离表示从“首行位于中心”移动到“末行中心位于中心”所需的位移。

滚动速度：

```text
speed = distance / durationSeconds
```

动画帧使用真实时间差推进：

```text
elapsed += min(frameDelta, maximumFrameDelta) / 1000
offset = min(speed * elapsed, distance)
```

当 `offset >= distance` 时停止动画并保持最终位置。暂停时保留 `elapsed`，继续时从暂停时刻接着计算。重置时恢复 `elapsed = 0` 和 `offset = 0`。

## 状态与重算

状态包括 `idle`、`playing`、`paused` 和 `finished`。

- 修改稿件、字号或背景后重新测量内容高度，并重置到初始位置。
- 修改时长时重新计算速度；播放中修改时长时保持当前位移，重置后才使用新速度从头计算。
- 预览区域尺寸变化时重新测量，并重置到初始位置，避免位置跳变。
- 空稿件时禁止开始，并显示无文字状态。

## 持久化

使用 `localStorage` 保存稿件、选区样式区间、字号、文字颜色、背景颜色和时长。每次有效修改后写入，页面加载时恢复。清空稿件同时清除对应选区样式。

## 选区样式

编辑器保持纯文本 `textarea`。用户选择一段文字后，可为该区间设置颜色和字号；预览使用 `span` 渲染样式区间。选区样式优先于全局默认样式。

当稿件发生变化时，通过前后文本的最长公共前缀和公共后缀计算编辑范围，再平移、扩展或裁剪所有样式区间。插入到样式区间内部时，新文字继承该区间样式；删除内容时，区间自动缩短或移除。

## 可访问性与全屏

- 所有按钮使用原生按钮并提供可读标签。
- 滑块和颜色输入使用关联的 `label`。
- 全屏使用 Fullscreen API，并在不支持时保持普通预览。
- 全屏后保留全部滚动控制；按 `Escape` 退出后恢复原布局。

## 测试策略

单元测试覆盖：

- 从首行中心到末行中心的滚动距离。
- 按总时长计算恒定速度。
- 播放、暂停、继续、完成和重置状态转移。
- 无效时长、短稿和零高度边界。

浏览器验收覆盖：

- 输入稿件后首行位于预览中心。
- 开始后持续向上移动，暂停后位置不变，继续后恢复。
- 重置后回到中心且计时归零。
- 字号、颜色和背景实时更新。
- 全屏进入和退出后控制仍可用。
- 5000 字稿件可正常开始、暂停和重置。
